# Amazon Affiliate YouTube Product Website

This is a ready-to-run static website for an Amazon Associates / YouTube product showcase.

## How to use
1. Open `index.html` in a browser.
2. Scroll to Product Manager.
3. Add your product name, category, image URL, description, and your Amazon Associates tracking URL.
4. The product will appear on the website.
5. Visitors click "View on Amazon" and are sent to Amazon.

## Important for a real Amazon Associates site
- Use your Amazon Associates tracking links.
- Follow the current Amazon Associates Program Operating Agreement and Product Advertising API/content rules.
- Do not copy/scrape Amazon prices, reviews, ratings or images unless your Associates tools/API/license permits that use.
- If you later want automatic Amazon product data, connect the site to the Amazon Product Advertising API rather than scraping Amazon.
- This starter's Product Manager saves to browser localStorage. It is not a secure shared admin panel.

## To publish
Upload `index.html` to a static host such as your own hosting, GitHub Pages, Cloudflare Pages, or Netlify. A custom domain can then be used in your YouTube bio.
